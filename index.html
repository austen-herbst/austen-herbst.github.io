Austen Home Bridge

This is a personal OAuth connection between ChatGPT and Google's Home MCP server. It lets its owner ask ChatGPT about a selected Google Home and request supported device actions. It is not offered as a public service.

Google's Home permission can allow reading Home data and controlling supported devices. Access requires the owner's Google authorization. The ChatGPT connection is private to the owner's account.

If you did not expect to authorize this connection, do not grant access.
